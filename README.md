# Data Structures and Algorithms in Java

## Overview
This repository contains implementations of various **Data Structures** and **Algorithms** in **Java**. Organized by topic, each subdirectory includes Java files demonstrating core concepts, operations, and applications.

Perfect for learning, revision, or reference!

## Topics Covered
- **Trees**: AVL Tree, Binary Search Tree (BST), B-Tree
- **Union-Find (Disjoint Set Union)**: Cycle Detection, Union by Rank, Union by Size
- **Graphs**: Graph representation using Linked Lists
- **Hash Tables**: Separate Chaining, Linear/Quadratic/Double Hashing, Rehashing
- **Heaps**: Heap operations
- **Linked Lists**: Singly, Doubly, Circular LL; Applications (e.g., Spotify playlist)
- **Prefix Computations**: Prefix Sum (1D/2D), Prefix XOR, GCD, Palindrome Hashing
- **Queues**: Queue using Linked Lists
- **Segment Trees**: Sum, XOR, LCM, RMQ, Lazy Propagation
- **Sparse Tables**: RMQ (Min/Max), GCD
- **Stacks**: Stack using Linked Lists
- **Tries**: Basic Trie, Word Replacement, Longest Common Prefix

## How to Use
1. **Compile a file**:
   ```bash
   javac Data-Structures/[Subdir]/[File].java
   ```

2. **Run a file** (e.g., Heaps):
   ```bash
   java -cp Data-Structures/Heaps Heaps
   ```

3. Open individual `.java` files in your IDE (VSCode, IntelliJ) for study. Most include main methods with examples.
